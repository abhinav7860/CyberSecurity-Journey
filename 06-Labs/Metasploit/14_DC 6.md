

# 3. Initial Nmap Enumeration

After identifying the target IP, I performed service enumeration.

### Command

### Why I used it

- `-sV` — attempts to identify the versions of services running on open ports.

# 16. Understand the RCE

The exploit targeted:

```text
/wp-[USER_1]/[USER_1].php?page=plainview_activity_monitor&tab=activity_tools
```

The vulnerable parameter was:

```text
ip
```

The exploit constructed a value similar to:

```text
google.fr | whoami
```

The `|` character acts as a shell command separator.

Conceptually:

```text
DNS lookup command
       +
shell separator
       +
our command
```

This resulted in arbitrary command execution on the server.

The exploit required authentication, which we already had through:

```text
[WORDPRESS_USER] : [WORDPRESS_PASSWORD]
```

# 22. Inspect the Backup Script

```bash

```

It contained:

```bash

```

The script itself simply created a compressed archive of the WordPress directory.

However, I then checked its permissions.

### Command

```bash

```

The important entry was:


This was critical.

Graham was a member of `[PRIV_GROUP]`, and the script's group was `[PRIV_GROUP]` with write permission.

Therefore:

```text
Graham

```

# 32. Key Security Lessons

### WordPress enumeration

Exposed author information can reveal valid usernames that can later be targeted for authentication attacks.

### Password hygiene

A password discovered through the DC-6 password-list clue allowed access to a WordPress account.

### Vulnerable plugins

The Plainview Activity Monitor plugin provided an authenticated command-injection path because of unsafe handling of user-controlled input.

### Sensitive files

A readable file in another user's home directory exposed credentials.

### Group permissions

The `[PRIV_GROUP]` group had write access to a script owned by Jens. This created a dangerous privilege boundary.

### Sudo configuration

Allowing users to execute writable scripts as another user can lead directly to privilege escalation.

### Nmap sudo permissions

Granting unrestricted root execution of a vulnerable/feature-rich binary such as an old Nmap version can provide another route to root.

### Version enumeration

The failed `--interactive` attempt demonstrated that exploitation techniques must match the installed software version.
