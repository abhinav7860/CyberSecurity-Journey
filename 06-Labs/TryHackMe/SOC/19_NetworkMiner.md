# Task 2 --- NetworkMiner in Forensics

## What is Network Forensics?

Network forensics is the process of collecting and investigating network
traffic to understand what happened on a network. The goal is to gather
enough evidence to identify malicious activity, security breaches,
suspicious behaviour and network anomalies.

The main types of network evidence covered were:

-   **Live Traffic** --- traffic observed while communication is
    happening.
-   **Traffic Captures** --- PCAP/PCAPNG files used for offline
    investigation.
-   **Log Files** --- records generated by network and security systems.

NetworkMiner is particularly useful for analysing captured traffic and
quickly identifying useful artefacts.

------------------------------------------------------------------------

# Task 3 --- What is NetworkMiner?

NetworkMiner is an open-source **Network Forensic Analysis Tool
(NFAT)**.

## Main capabilities

### Traffic sniffing

NetworkMiner has a sniffing feature, but it is not intended to replace
dedicated sniffers such as Wireshark or tcpdump.

### PCAP parsing

NetworkMiner can load PCAP files and automatically process their
contents.

### OS fingerprinting

It can identify probable operating systems from captured traffic. The
room mentions technologies such as **Satori** and **p0f**.

### File extraction

It can reconstruct files such as images, HTML and other transferred
data.

### Credential extraction

It can extract authentication-related artefacts such as:

-   Kerberos hashes
-   NTLM hashes
-   HTTP credentials/cookies
-   FTP
-   SMTP
-   IMAP
-   MS SQL data

### Cleartext keyword parsing

It can search processed traffic for specific words and strings.

------------------------------------------------------------------------

## Operating Modes

### Sniffer Mode

This allows NetworkMiner to observe live traffic, but the room
recommends not using it as the primary sniffer.

### Packet Parsing / Processing

This is the mode I mainly care about. I can load a PCAP and get a quick
overview of the hosts, sessions, DNS, credentials, files and other
artefacts.

My basic workflow is:

``` text
PCAP
  ↓
NetworkMiner
  ↓
Quick forensic overview
  ↓
Find interesting artefacts
  ↓
Wireshark for deeper investigation
```

# NetworkMiner vs Wireshark

  Feature                NetworkMiner   Wireshark
  ---------------------- -------------- ---------------
  Quick PCAP overview    Excellent      Good
  PCAP handling          Yes            Yes
  OS fingerprinting      Yes            No
  File extraction        Yes            Yes
  Credential discovery   Yes            Yes
  Keyword discovery      Yes            Mostly manual
  Detailed filtering     Limited        Excellent
  Packet decoding        Limited        Excellent
  Protocol analysis      Limited        Excellent
  Payload analysis       Limited        Excellent
  Statistical analysis   Limited        Excellent


# Task 4 --- Tool Overview 1

## Case Panel

The Case Panel shows the loaded PCAP files. I can refresh cases, remove
files and view metadata.

Useful option:


The Hosts section can show:

-   IP address

Sessions provide:

-   Frame number
-   Client/server
-   Source/destination ports
-   Protocol
-   Start time

The search supports:

``` text
ExactPhrase
AllWords
AnyWord
RegExe
```

## DNS

The DNS section can show:

-   Frame number
-   Timestamp
-   Client/server
-   Ports
-   TTL
-   DNS time
-   Transaction ID
-   Query type
-   DNS query/answer

## Credentials

The Credentials section shows extracted credentials and hashes from the
PCAP. This is useful for quickly identifying authentication artefacts.

# Task 6 --- Version Differences

The VM contained two major NetworkMiner versions:

``` text
1.6
2.7
```

The versions have different features.

Version 2.x introduced MAC-address-specific correlation, which is useful
for identifying duplicate MAC/address relationships.

Version 1.6 has older packet/frame-level views that are no longer
available in the same way in newer versions.

This mattered in the practical exercise because I had to switch versions
depending on the question.

### Answers

**Which version can detect duplicate MAC addresses?**

``` text
2.7
```

**Which version can handle frames?**

``` text
1.6
```

**Which version can provide more details on packet details?**

``` text
1.6
```

### Important lesson

I should not assume the newest version is always the correct version.
Tool versions can expose different forensic information.

# My NetworkMiner Investigation Workflow

packet.

My preferred workflow is:

``` text
1. Load PCAP
        ↓
2. Check Case / Metadata
        ↓
3. Check Hosts
        ↓
4. Check Sessions
        ↓
5. Check DNS
        ↓
6. Check Credentials
        ↓
7. Check Files / Images
        ↓
8. Check Parameters / Keywords
        ↓
9. Check Messages
        ↓
10. Check Anomalies
        ↓

        ↓

```

# What I Learned

The biggest thing I learned is that network forensics does not always
mean manually inspecting every packet.

A large PCAP can contain a huge amount of traffic. NetworkMiner helps
reduce the initial workload by automatically organising useful
artefacts.

I learned how to use:

-   **Hosts** for machines and OS information.
-   **Sessions** for communication details.
-   **DNS** for domain activity.
-   **Credentials** for authentication artefacts.
-   **Files** for transferred files.
-   **Images** for reconstructed images.
-   **Parameters** for extracted values.
-   **Keywords** for targeted searches.
-   **Messages** for email/chat investigation.
-   **Anomalies** for possible suspicious activity.

The version comparison was also important. Some questions could only be
answered efficiently by switching between NetworkMiner 1.6 and 2.7.

Most importantly, I now have a better idea of how NetworkMiner fits into
a SOC workflow.

> **NetworkMiner is good for fast triage and finding the low-hanging
> fruit. Wireshark is better when I need to understand exactly what
> happened at packet level.**

So the workflow I want to remember is:

``` text
PCAP
 ↓
NetworkMiner
 ↓
Initial triage
 ↓
Find hosts / sessions / credentials / files / anomalies
 ↓
Wireshark
 ↓
Deep packet investigation
 ↓
Confirm evidence
 ↓
Document the finding
```
