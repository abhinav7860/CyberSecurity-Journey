# What is a Junior Security Analyst?

A Junior Security Analyst is the **first line of defense** in a Security Operations Center (SOC).

Main responsibilities include:

- Monitoring security alerts.
- Investigating suspicious activities.
- Escalating serious incidents.
- Working with other security teams.
- Continuously learning about new attacks and defenses.

---

# What is a SOC?

SOC stands for **Security Operations Center**.

It is a team responsible for monitoring, detecting, investigating, and responding to cyber security incidents 24/7.

The goal of a SOC is to detect threats early and protect the organization's systems.

---

# SOC Team Roles

### Junior Security Analyst (SOC Level 1)

- Monitors alerts.
- Performs initial investigation.
- Escalates serious cases.

### Senior Analyst

- Handles complex investigations.
- Helps junior analysts.
- Reviews escalated alerts.

### SOC Engineer

- Configures and maintains security tools.
- Creates detection rules and automations.
- Improves alert quality.

### SOC Manager

- Manages the SOC team.
- Reports security status to management.
- Ensures smooth SOC operations.

### Incident Responder

- Handles major security incidents like ransomware attacks.
- Joins during high-severity incidents.

# Key Learning

One important responsibility of a Junior Security Analyst is **knowing when to escalate** an incident.

If an alert is critical or requires deeper investigation, it should be escalated to a **Senior Analyst** instead of trying to solve everything alone.
