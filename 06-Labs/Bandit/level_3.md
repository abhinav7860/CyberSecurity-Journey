# Bandit Level 3 → Level 4

## Objective

Find the password stored in the hidden file inside the `inhere` directory.

## Commands Used

```bash
cd inhere
ls -a
cat .hidden
```

## What I Learned

- `cd` is used to move into a directory.
- `ls -a` shows all files, including hidden files.
- Hidden files start with a `.` (dot).
- `cat` is used to read the contents of a file.
