## What is Linux?

Linux is an **operating system**, just like Windows and macOS.

It manages the computer hardware and provides the environment where applications run.

Some important things about Linux:

- It is open source.
- It is free to use and modify.
- It has many distributions (distros).
- Ubuntu is beginner-friendly.
- Kali Linux is designed for security testing.
- Other distributions are used for servers and different purposes.

Linux is not necessarily difficult. Modern Linux distributions also have graphical interfaces. The reason cybersecurity focuses so much on the command line is because it gives much more direct control over the system.

I also learned that Linux is already everywhere. A large number of internet servers run Linux, and Android is also based on the Linux kernel.

## Why Linux is Important in Cybersecurity

There are a few main reasons Linux is so important for cybersecurity.

### 1. Many servers run Linux

A lot of web servers, cloud infrastructure and backend systems use Linux.

So if I want to work in cybersecurity, I need to understand the systems I may be defending or testing.

### 2. Security tools run on Linux

A lot of security tools are designed for Linux or work especially well there.

Examples I have already come across include:

- Wireshark
- Snort
- Suricata
- Kali Linux security tools

This makes Linux a very common environment for security work.

### 3. The command line is powerful

The terminal lets me control the system directly using commands.

It is useful because commands can be:

- Precise
- Combined together
- Automated
- Used remotely

This becomes especially important for cybersecurity because security professionals often need to process large amounts of information or work with remote systems.

### 4. Linux is open source

Because Linux is open source, its behaviour and configuration can be inspected in detail.

For security work, being able to inspect what a system is doing is very useful.

## Why Use the Command Line?

The command line can feel difficult at first because there are no buttons telling me what to click.

Instead, I have to know the command I want to use.

But it has some major advantages.

### Precision

Commands allow me to perform specific actions very precisely.

For example, instead of manually changing hundreds of files, I can use a command to process them according to a pattern.

### Combining Commands

One of the biggest advantages is that command-line tools can be combined.

The output from one command can be passed to another command.

I will learn more about this later in the course, especially when pipes are introduced.

### Automation

Commands can be saved into scripts.

This means repetitive tasks can be automated instead of being done manually every time.

This will become important when I start learning scripting.

### Remote Access

The command line is also useful for working with remote systems.

Servers are often somewhere else and may not have a graphical interface available. Tools such as SSH allow administrators and security professionals to work with these systems remotely.

## Important Terms

| Term | Meaning |
|---|---|
| Linux | An operating system/kernel ecosystem widely used on servers and other systems |
| Distribution / Distro | A packaged Linux operating system such as Ubuntu, Debian or Kali |
| Terminal | An application used to interact with the command line |
| Shell | The program that interprets commands |
| CLI | Command-Line Interface |
| GUI | Graphical User Interface |
| SSH | A protocol used for secure remote access |

## Linux vs GUI

A graphical interface is easier for beginners because it shows buttons, menus and icons.

The command line has a bigger learning curve because I need to know what commands to type.

But once I become comfortable with it, the command line gives me:

- More control
- More precision
- Faster workflows
- Automation
- Easy remote access
- The ability to combine tools

So the goal is not to avoid the GUI completely. It is to become comfortable enough with the command line that I can use it when it is the better tool.
