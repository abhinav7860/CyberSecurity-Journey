# What is a Proxy?

A **Proxy Server** is an intermediary server that sits between a client and the destination server.

Instead of communicating directly with a website, the client sends requests to the proxy. The proxy then forwards the request to the destination server and returns the response to the client.

Unlike a VPN, which tunnels **all network traffic**, a proxy usually handles only specific types of traffic, such as HTTP or HTTPS.

---

# Proxy vs VPN

| Proxy | VPN |
|--------|-----|
| Usually handles only specific traffic (HTTP/HTTPS) | Encrypts all network traffic |
| Primarily used for filtering, monitoring and control | Primarily used for privacy and secure communication |
| May or may not encrypt traffic | Always encrypts traffic between client and VPN server |
| Commonly deployed by organizations | Commonly deployed by users or organizations |
| Often used for caching and access control | Used for secure remote access and privacy |

---

# Types of Proxies

## 1. Forward Proxy

A Forward Proxy sits between internal users and the internet.

### Common Uses

- Web filtering
- Internet access control
- Logging user activity
- Malware filtering
- Website blocking
- Caching

### Example

```
User
   │
Forward Proxy
   │
Internet
```

Most enterprise environments use Forward Proxies to monitor employee web traffic.

Examples:

- Squid
- Zscaler
- Netskope

---

## 2. Reverse Proxy

A Reverse Proxy sits in front of web servers instead of users.

Clients communicate with the Reverse Proxy instead of directly accessing the web server.

### Common Uses

- Load balancing
- TLS termination
- Web Application Firewall (WAF)
- DDoS protection
- Caching

### Example

```
Internet
     │
Reverse Proxy
     │
Web Server
```

Examples:

- Nginx
- Cloudflare
- AWS CloudFront
- HAProxy

---

## 3. Transparent Proxy

A Transparent Proxy intercepts traffic without requiring any client configuration.

Users generally don't know they are using one.

Common locations include:

- Schools
- Universities
- Hotels
- Airports
- Coffee shops

Typical purposes:

- Web filtering
- Logging
- Bandwidth management

---

# Functions of Proxy Servers

Proxy servers provide several important capabilities.

## Content Filtering

Organizations can block categories of websites such as:

- Social Media
- Gambling
- Adult Content
- Malicious Websites

---

## Security Inspection

Modern secure web gateways inspect web traffic for:

- Malware
- Phishing
- Command & Control traffic
- Data Exfiltration

Some proxies perform **TLS Inspection**, allowing encrypted HTTPS traffic to be inspected after decrypting it.

---

## Caching

Frequently accessed resources can be stored locally.

Benefits include:

- Faster page loading
- Reduced bandwidth consumption
- Lower server load

---

## Anonymization

Some public proxies hide a user's IP address.

However:

- Most free public proxies should not be trusted.
- They may log or modify user traffic.

---

## Load Balancing

Reverse proxies distribute incoming traffic across multiple backend servers.

Benefits:

- High availability
- Better performance
- Scalability

---

## TLS Termination

Instead of each web server handling HTTPS encryption individually, the reverse proxy performs encryption and forwards decrypted traffic internally.

Benefits:

- Easier certificate management
- Reduced server workload

---

# Trust Considerations

Every proxy operator can potentially:

- View traffic
- Log requests
- Modify responses

Examples:

### Corporate Proxy

Your employer may monitor:

- Browsing history
- Downloaded files
- HTTPS traffic (if TLS inspection is enabled)

---

### Public Wi-Fi

Hotels, airports and coffee shops often use transparent proxies.

They may:

- Filter websites
- Monitor browsing
- Limit bandwidth

---

### Public Anonymous Proxies

Generally considered unsafe.

Risks include:

- Credential theft
- Traffic interception
- Malware injection

---

### Reverse Proxies

When accessing websites protected by:

- Cloudflare
- AWS CloudFront
- Fastly

your requests first reach those services before the actual web server.

---

# Proxies vs VPNs

Although similar, they serve different purposes.

## VPN

- Encrypts all traffic
- Changes public IP
- Protects all applications
- Provides secure tunneling

---

## Proxy

- Usually handles web traffic only
- May not encrypt traffic
- Primarily used for monitoring and filtering
- Often deployed by organizations

# Test 1 - Detect Proxy using Public IP Services

Visited:

- whatismyipaddress.com
- browserleaks.com
- whoer.net

Purpose:

Determine whether the current connection appears to originate from:

- Home Network
- VPN
- Proxy
- Tor

---

## Observation

My connection showed:

**Public IPv6**

```
2404:6800:4007:817::200e
```

**Public IPv4**

```
10.57.3.141 (Private RFC1918 Address during the lab environment)
```

The lookup indicated the address belonged to the **Private 10.0.0.0/8 network**, showing that the environment was using internal/private addressing rather than exposing a direct public IP.

### What I Learned

- Public IP lookup tools help identify whether traffic is passing through VPNs or proxies.
- Private IP ranges (RFC1918) are not routable on the public Internet.
- In lab environments, proxy or NAT configurations may expose internal addressing.

---

# Test 2 - Network Path Analysis

Executed:

```cmd
tracert google.com
```

Output showed approximately:

- Hop 1 → Local Router
- Hop 2–3 → ISP Routers
- Remaining hops → Internet backbone
- Final destination → Google

Example:

```
1  Router

2  ISP

3  ISP

...

10 google.com
```

### Observation

No obvious corporate proxy server appeared in the routing path.

The route followed a normal ISP path toward Google's infrastructure.

### What I Learned

Traceroute helps identify:

- Routers
- ISPs
- Enterprise gateways
- Unexpected intermediary devices

---

# Test 3 - Reverse Proxy Detection

Used Browser Developer Tools (F12).

Opened:

```
Network Tab
```

Inspected Response Headers.

Looked for common reverse proxy indicators such as:

```
Server: cloudflare

Server: nginx

X-Served-By

X-Cache

X-Amz-Cf-Id
```

These headers reveal whether websites are protected by reverse proxies or CDNs.

### What I Learned

Many modern websites are protected by:

- Cloudflare
- AWS CloudFront
- Fastly
- Akamai

rather than exposing the origin server directly.
