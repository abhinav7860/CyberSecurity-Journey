## 1. Root Directory `/`

`/` is the top of the Linux filesystem.

For example:

```text
/home/user/documents
```

This means starting from `/`, going into `home`, then `user`, then `documents`.

I also learned that **root directory** and **root user** are different:

- `/` = root directory
- `root` = administrator/superuser account

## 2. Important Directories

| Directory | What I learned |
|---|---|
| `/home` | Personal directories of normal users |
| `/etc` | System configuration files |
| `/var` | Variable data |
| `/var/log` | System and application logs |
| `/usr` | Installed programs and supporting files |
| `/bin` | Essential command-line programs |
| `/sbin` | System administration programs |
| `/tmp` | Temporary files |
| `/root` | Home directory of the root user |
| `/dev` | Device files |
| `/proc` | Information about processes and the system |

For cybersecurity, I especially want to remember:

`/etc` → configuration  
`/var/log` → logs  
`/tmp` → temporary files

## 3. Absolute and Relative Paths

### Absolute Path

An absolute path starts from `/` and gives the complete location.

```text
/home/user/documents/report.txt
```

It works no matter where I currently am.

### Relative Path

A relative path starts from my current location.

```text
documents/report.txt
```

It depends on where I am in the filesystem.

### Useful symbols

```text
.   = current directory
..  = parent directory
~   = home directory
```

For example, if I am in:

```text
/home/user/documents
```

then:

```text
..      → /home/user
../..   → /home
```

So the simple difference is:

**Absolute = starts from `/`**  
**Relative = starts from where I currently am**

## 4. Everything Is a File

One of the interesting things I learned is that Linux treats almost everything as a file or through a file-like interface.

This includes:

- Hardware devices → `/dev`
- Running processes → `/proc`
- System information
- Configuration
- Logs

This makes Linux consistent because many things can be inspected using similar file-handling commands.

For cybersecurity, this is useful because investigating a Linux system often means knowing which files to look at.

- `/dev` contains device files.
- `/proc` contains process and system information.
- Absolute paths start with `/`.
- Relative paths start from the current directory.
- `.` means current directory.
- `..` means parent directory.
