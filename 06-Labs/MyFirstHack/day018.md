# Why Learn the Attacker's Perspective?

A good defender doesn't just know how to secure systems—they understand **how attackers think**.

Knowing the attack process helps defenders:

- Detect attacks earlier
- Break the attack before damage occurs
- Build better security controls
- Understand real-world incident reports

> **Key Idea:** You don't study attacks to become an attacker—you study them to become a better defender.

---

# The Cyber Kill Chain

The **Cyber Kill Chain** is a framework developed by **Lockheed Martin** in **2011**.

It describes the typical stages an attacker follows during a cyber attack.

If defenders stop the attack at **any stage**, the remaining stages cannot happen.

---

## Stage 1 – Reconnaissance

The attacker gathers information about the target.

Examples:

- Company websites
- LinkedIn profiles
- Job postings
- DNS records
- Public databases
- Leaked credentials

Questions attackers ask:

- What technologies are being used?
- Who works there?
- What email format is used?

### Goal

Collect as much information as possible before attacking.

---

## Stage 2 – Weaponization

The attacker prepares the attack.

Examples:

- Phishing emails
- Malicious Office documents
- Fake login pages
- Malware payloads
- Exploits

### Goal

Create a weapon specifically designed for the target.

---

## Stage 3 – Delivery

The attacker sends the weapon to the victim.

Common delivery methods:

- Email
- Malicious websites
- USB drives
- SMS (Smishing)
- Social media
- Supply chain attacks

### Goal

Deliver the malicious content to the target.

---

## Stage 4 – Exploitation

The attack is triggered.

Examples:

- User clicks a phishing link
- Opens an attachment
- Visits a malicious website
- Software vulnerability is exploited

### Goal

Gain initial access to the victim's system.

---

## Stage 5 – Installation

The attacker establishes persistence.

Examples:

- Install malware
- Create a backdoor
- Schedule malicious tasks
- Modify startup programs

### Goal

Maintain access even after reboot.

---

## Stage 6 – Command and Control (C2)

The infected machine communicates with the attacker's server.

The attacker can:

- Execute commands
- Upload malware
- Download stolen files
- Control the compromised machine remotely

### Goal

Maintain communication with the compromised system.

---

## Stage 7 – Actions on Objectives

The attacker performs their final objective.

Examples:

- Steal sensitive data
- Deploy ransomware
- Delete files
- Move laterally
- Encrypt systems
- Financial fraud

### Goal

Achieve the purpose of the attack.

---

# Cyber Kill Chain Summary

| Stage | Description |
|--------|-------------|
| 1 | Reconnaissance |
| 2 | Weaponization |
| 3 | Delivery |
| 4 | Exploitation |
| 5 | Installation |
| 6 | Command & Control |
| 7 | Actions on Objectives |

> **Easy Way to Remember:**
>
> **Research → Build → Deliver → Exploit → Install → Control → Attack**

# Capital One Breach Example

The Capital One incident can be mapped to the Cyber Kill Chain.

| Kill Chain Stage | Example |
|------------------|---------|
| Reconnaissance | Scanned AWS accounts for vulnerable WAFs |
| Weaponization | Crafted an SSRF request |
| Delivery | Sent HTTP request to the WAF |
| Exploitation | Retrieved AWS metadata credentials |
| Installation | No malware installed (used temporary credentials) |
| Command & Control | Used AWS API calls through Tor |
| Actions on Objectives | Downloaded data from S3 buckets |

### Lesson

The visible damage happened only at **Stage 7**, but the attack actually began much earlier.

---

# Limitations of the Cyber Kill Chain

Real attacks don't always follow the stages in order.

Examples:

- Reconnaissance continues throughout the attack.
- Attackers may create malware before choosing a target.
- Multiple persistence mechanisms may be installed.
- Attackers often move laterally across systems.
- Several stages can occur simultaneously.

Because of these limitations, the industry also uses **MITRE ATT&CK**.

---

# MITRE ATT&CK Framework

MITRE ATT&CK stands for:

**Adversarial Tactics, Techniques, and Common Knowledge**

It is the most widely used cybersecurity framework for describing attacker behavior.

Unlike the Kill Chain, it provides much more detailed information.

---

# Tactics

Tactics describe **why** an attacker performs an action.

Examples:

- Initial Access
- Execution
- Persistence
- Privilege Escalation
- Defense Evasion
- Credential Access
- Discovery
- Lateral Movement
- Collection
- Command and Control
- Exfiltration
- Impact

There are **14 tactics** in total.

---

# Techniques

Techniques describe **how** an attacker performs a tactic.

Examples:

| Technique | MITRE ID |
|-----------|-----------|
| Phishing | T1566 |
| Exploit Public-Facing Application | T1190 |
| Lateral Tool Transfer | T1570 |

MITRE currently documents:

- 200+ techniques
- Hundreds of sub-techniques

---

# Why MITRE ATT&CK Matters

Security professionals use ATT&CK to:

- Investigate incidents
- Build detection rules
- Perform threat hunting
- Conduct penetration tests
- Share threat intelligence

Many security vendors reference MITRE IDs in their reports.

Example:

```
T1190 – Exploit Public-Facing Application

T1566 – Phishing

T1041 – Exfiltration Over C2 Channel
```

# Breaking the Kill Chain

The defender's goal is **not** to wait until damage occurs.

Instead, stop the attacker as early as possible.

Examples:

| Stage | Defensive Action |
|--------|------------------|
| Reconnaissance | Block suspicious IPs |
| Delivery | Email filtering |
| Exploitation | Patch vulnerabilities |
| Installation | Antivirus / EDR |
| Command & Control | Monitor outbound traffic |
| Actions on Objectives | Data Loss Prevention (DLP) |

Stopping an attacker early greatly reduces damage.

---

# Defense in Depth

No single security control can stop every attack.

Organizations use multiple layers of security.

Examples:

- Firewall
- Email Security
- Antivirus
- Endpoint Detection & Response (EDR)
- Multi-Factor Authentication (MFA)
- Network Monitoring
- Security Information and Event Management (SIEM)

If one layer fails, another may detect or block the attack.

---

# Command and Control (C2)

C2 is the communication channel between the attacker and the compromised machine.

The attacker uses it to:

- Run commands
- Upload malware
- Download stolen data
- Maintain remote access

SOC analysts closely monitor network traffic to identify suspicious C2 communications.

Blocking C2 often prevents the attacker from completing their objectives.

---

# Cyber Kill Chain vs MITRE ATT&CK

| Cyber Kill Chain | MITRE ATT&CK |
|------------------|--------------|
| High-level attack stages | Detailed attacker behaviors |
| 7 stages | 14 tactics and 200+ techniques |
| Easier for beginners | Used by security professionals |
| Focuses on attack progression | Focuses on attacker methods |
