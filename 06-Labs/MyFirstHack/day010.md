# Why Data Matters

Everything I've studied so far exists to protect data.

Examples of major data breaches:

- **Equifax** – Personal records of 147 million people
- **Yahoo** – 3 billion user accounts
- **Marriott** – 500 million customer records
- **LastPass** – Encrypted password vaults
- **Colonial Pipeline** – Operational systems and business data

The technology changes, but the target remains the same:

> **Data is the real asset attackers want.**

# The Three Categories of Data

One of the biggest lessons today was learning that almost every valuable piece of information falls into three categories.

---

# 1. Personally Identifiable Information (PII)

PII is any information that can identify a person.

Examples:

- Full Name
- Address
- Phone Number
- Email Address
- Date of Birth
- Passport Number
- Driving License
- Aadhaar Number
- PAN Card
- Medical Records
- Fingerprints
- Face Recognition Data

### Why attackers want PII

Stolen personal information can be used for:

- Identity theft
- Bank fraud
- Insurance fraud
- Targeted scams
- Fake account creation
- Selling on the dark web

---

## Example

### Equifax Breach (2017)

Attackers exploited an unpatched vulnerability and stole:

- Names
- Social Security Numbers
- Birth Dates
- Addresses
- Driver's License Numbers

The biggest problem wasn't passwords.

You can change a password.

You **cannot change your birthday or identity.**

---

# 2. Credentials

Credentials prove who you are.

Examples include:

- Passwords
- Password Hashes
- Session Tokens
- API Keys
- SSH Keys
- OAuth Tokens
- 2FA Recovery Codes
- TLS Certificates

---

## Why attackers want credentials

Credentials provide direct access to systems.

With stolen credentials, attackers can:

- Log into accounts
- Access company networks
- Move laterally
- Install malware
- Deploy ransomware

---

## Example

### Twitter Bitcoin Hack (2020)

Attackers phished Twitter employees.

Instead of stealing personal data, they stole **internal admin credentials**.

Those credentials allowed attackers to take over verified accounts such as:

- Elon Musk
- Barack Obama
- Joe Biden
- Apple

This demonstrated how dangerous stolen credentials can be.

---

# 3. Proprietary Data

Proprietary data belongs to an organization.

Examples include:

- Source Code
- Business Documents
- Internal Emails
- Customer Database
- Product Designs
- Financial Reports
- Trade Secrets
- Strategic Plans

---

## Why attackers steal proprietary data

Reasons include:

- Corporate espionage
- Financial gain
- Extortion
- Competitive advantage
- Ransomware
- Stock manipulation

---

## Example

### Sony Pictures Hack (2014)

Attackers stole:

- Unreleased movies
- Employee information
- Executive emails
- Internal documents
- Scripts

The leaked information caused major financial and reputational damage.

# Why Some Data Is More Valuable

Not all data has the same value.

The value depends mainly on two things:

- Permanence
- Leverage

---

# Permanence

Some information can easily be replaced.

Examples:

- Credit Card
- Password
- Session Token

These can be changed quickly.

Other information lasts forever.

Examples:

- Date of Birth
- Medical History
- Fingerprints
- Face Recognition
- Aadhaar

These cannot be replaced.

The more permanent the data, the more valuable it becomes.

---

# Leverage

Some information gives attackers immediate power.

Examples:

- Administrator Password
- VPN Credentials
- API Keys
- AWS Access Keys

Even if these credentials exist for only a few minutes, they can allow attackers to:

- Install malware
- Create backdoors
- Download confidential data
- Encrypt company systems

# Thinking Like a Security Professional

One of the most important lessons today was learning how security professionals analyze systems.

Instead of asking:

> "How does this application work?"

They first ask three questions.

---

## Question 1

### What data does this system store?

Examples:

- Customer database
- Passwords
- Payment information
- Source code

---

## Question 2

### Which category does it belong to?

- PII
- Credentials
- Proprietary Data

Sometimes it may contain all three.

---

## Question 3

### Who wants this data?

Possible attackers:

- Cybercriminals
- Hacktivists
- Competitors
- Nation-state attackers
- Insider threats

Understanding who wants the data helps determine the security measures required.
