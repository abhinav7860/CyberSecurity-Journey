# Objective

Today I learned about **IP Addresses**, which are the unique identifiers assigned to every device connected to a network. Before today, I only knew websites by their names like `google.com`, but I learned that computers actually communicate using numerical IP addresses.

I also learned the difference between public and private IP addresses, how NAT works, why IPv6 was introduced, and why IP addresses are valuable to both defenders and attackers.

---

# What is an IP Address?

An **IP (Internet Protocol) Address** is a unique numerical address assigned to a device on a network.

Computers do not understand names like:

```
google.com
facebook.com
reddit.com
```

Instead, they communicate using IP addresses such as:

```
142.250.191.46
157.240.241.35
151.101.1.140
```

Domain names are for humans.

IP addresses are for computers.

---

# IPv4 Address Format

An IPv4 address consists of four decimal numbers separated by dots.

Example:

```
192.168.1.10
```

Each number ranges from:

```
0 - 255
```

Example IPv4 addresses:

```
8.8.8.8
1.1.1.1
142.250.191.46
192.168.1.5
```

---

# Public vs Private IP Addresses

## Public IP

A Public IP address is visible on the internet.

It is assigned by an ISP (Internet Service Provider).

Example:

```
142.250.191.46
```

Characteristics:

- Globally unique
- Reachable from anywhere on the internet
- Used for communication between networks

---

## Private IP

Private IP addresses are only used inside local networks.

Common ranges are:

```
10.0.0.0/8

172.16.0.0 – 172.31.255.255

192.168.0.0/16
```

Examples:

```
192.168.1.15

192.168.0.100

10.0.0.5
```

Private IPs cannot be accessed directly from the internet.

---

# Every Device Has Two IP Addresses

One concept that really stood out today was that a device usually has **two IP addresses**.

### Private IP

Assigned by the home router.

Example:

```
192.168.1.20
```

Only devices inside the same network can see this address.

---

### Public IP

Assigned by the ISP.

Example:

```
49.xxx.xxx.xxx
```

Every device in the home network shares this public IP when accessing the internet.

---

# NAT (Network Address Translation)

Since IPv4 addresses are limited, routers perform **Network Address Translation (NAT).**

NAT translates many private IP addresses into one public IP.

Example:

```
Laptop
192.168.1.10

Phone
192.168.1.11

TV
192.168.1.12

↓

Router (NAT)

↓

Single Public IP

49.xxx.xxx.xxx
```

Without NAT, the internet would have run out of IPv4 addresses much earlier.

---

# Localhost (127.0.0.1)

One special IP address is:

```
127.0.0.1
```

This is called:

**Localhost**

It always points back to the same computer.

It is commonly used for:

- Testing applications
- Running local web servers
- Development
- Troubleshooting

The computer is essentially communicating with itself.

---

# IPv4 Address Exhaustion

IPv4 provides approximately:

```
4.3 Billion
```

possible addresses.

When IPv4 was designed, this seemed more than enough.

However, with billions of:

- Phones
- Computers
- Routers
- Smart TVs
- IoT devices

the address space became exhausted.

The global IPv4 pool officially ran out in **2011**.

---

# Solutions to IPv4 Exhaustion

## 1. NAT

Allows multiple devices to share a single public IP.

This is the solution most home networks use today.

---

## 2. IPv6

IPv6 is the long-term replacement for IPv4.

Example:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

Characteristics:

- Uses hexadecimal numbers
- 128-bit addressing
- Massive address space
- Designed to replace IPv4

Although IPv6 adoption is increasing, IPv4 is still widely used.

# What Can Someone Learn From My Public IP?

I learned that simply knowing someone's public IP can reveal a surprising amount of information.

Possible information includes:

- Country
- City (approximate)
- Internet Service Provider
- Connection type
- VPN usage
- Hosting provider
- Mobile or broadband network

This information is publicly available and doesn't require hacking.

---

# Why IP Addresses Matter in Cybersecurity

Almost every network attack begins with an IP address.

Attackers use IPs to identify potential targets.

Common uses include:

### Port Scanning

Finding open services running on a device.

Example:

```
SSH
HTTP
HTTPS
FTP
SMB
```

---

### Reputation Checks

Checking whether an IP:

- Appears on spam blacklists
- Belongs to a VPN
- Is a Tor exit node
- Has been involved in previous attacks

---

### Geolocation

Determining the approximate location of a user based on their IP address.

---

### DDoS Attacks

Attackers flood a public IP with massive amounts of traffic to overwhelm the target and make services unavailable.

---

### Social Engineering

Attackers can tailor phishing or scam attempts using information inferred from a victim's IP address, such as their approximate location or ISP.

---

# Real-World Importance

Every website I visit automatically sees my public IP address.

It is used for:

- Routing traffic
- Logging access
- Detecting fraud
- Applying geographic restrictions
- Security monitoring

IP addresses play a key role in both networking and cybersecurity.
