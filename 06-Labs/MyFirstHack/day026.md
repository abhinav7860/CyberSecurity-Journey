# Overview

Website footprinting is the process of gathering publicly available information about a domain to understand its infrastructure, ownership, technologies, and exposed assets.

Unlike active reconnaissance, passive reconnaissance does **not** send traffic that directly interacts with the target's servers. Instead, it relies on publicly accessible sources such as DNS records, WHOIS databases, certificate transparency logs, and technology profiling services.

The information gathered during passive reconnaissance helps analysts understand an organization's attack surface while remaining completely non-intrusive.

---

# Passive vs Active Reconnaissance

One of the first concepts introduced in this lesson is understanding the difference between passive and active reconnaissance.

## Passive Reconnaissance

Passive reconnaissance collects information that is already publicly available.

Examples include:

- DNS records
- WHOIS information
- Certificate Transparency logs
- Public technology profiling websites
- Public search engines
- Archived web pages

The target's servers are **not directly contacted**, making passive reconnaissance difficult for the target to detect.

---

## Active Reconnaissance

Active reconnaissance directly interacts with the target's infrastructure.

Examples include:

- Port scanning
- Vulnerability scanning
- Service enumeration
- Directory brute forcing
- Login attempts
- Aggressive web crawling

These activities generate traffic that is typically logged by the target and should only be performed with proper authorization.

# Rules of Passive Reconnaissance

This lesson emphasizes three important professional guidelines:

### 1. Never scan systems you do not own

Do not perform:

- Nmap scans
- Nessus scans
- Vulnerability scans
- Port scans

without explicit written authorization.

---

### 2. Never attempt authentication

Avoid:

- Logging into accounts
- Testing credentials
