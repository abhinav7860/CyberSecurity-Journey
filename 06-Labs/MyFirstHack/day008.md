# Introduction

Today's lesson completely changed how I think about passwords.

# The Old Password Rules

For many years, organizations required passwords like:

```
P@ssw0rd2024!
```

Rules included:

- One uppercase letter
- One lowercase letter
- One number
- One special character
- Change every 90 days

I learned that these recommendations came from **Bill Burr (NIST)** in 2003.

Interestingly, Bill Burr later admitted that these recommendations were a mistake.

In 2017, NIST updated its password guidelines because forcing users to create overly complex passwords actually made security worse.

# How Passwords Actually Get Stolen

I learned that attackers rarely sit and guess random passwords.

Instead, they use smarter techniques.

---

# 1. Credential Stuffing

This is currently the most common password attack.

Attackers obtain usernames and passwords from previous data breaches.

Then they simply try the same credentials on other websites.

Example:

```
LinkedIn Password
↓

Try the same password on

Gmail
Amazon
Facebook
Banking Apps
Netflix
```

If I reuse passwords, one breach can compromise many accounts.

This is why password reuse is extremely dangerous.

---

# 2. Phishing

Instead of hacking the password, attackers trick users into giving it away.

Example:

```
Fake Banking Website

↓

User enters password

↓

Attacker receives it
```

The strength of the password doesn't matter if I type it into a fake website.

---

# 3. Dictionary Attack

Instead of trying every possible password, attackers use lists of commonly used passwords.

Examples:

```
password123

welcome123

summer2024

companyname2024

qwerty
```

Modern computers can test billions of these passwords every second.

---

# 4. Password Spraying

Instead of trying many passwords on one account...

Attackers try one common password on thousands of accounts.

Example:

```
Welcome123

↓

Employee1

Employee2

Employee3

Employee4
```

Since each account only receives one login attempt, many security systems don't immediately block it.

This attack is common in corporate environments.

---

# Why Password Complexity Isn't Enough

Old advice focused on making passwords look complicated.

Example:

```
P@ssw0rd!
```

Modern cybersecurity focuses more on:

- Length
- Uniqueness
- Randomness

A long password is mathematically much stronger than a short complex password.

---

# Length Beats Complexity

I learned an important concept today.

Every additional character increases the number of possible password combinations dramatically.

Example:

```
8-character password

↓

Much weaker
```

vs

```
20-character passphrase

↓

Much stronger
```

Example:

```
correcthorsebatterystaple
```

Even though it contains only lowercase letters, it is significantly stronger than:

```
P@ssw0rd!
```

This is because password strength grows exponentially with length.

---

# Modern Password Recommendations (NIST)

Current best practices recommend:

- Longer passwords
- Passphrases
- No forced password changes unless compromised
- Unique passwords for every account

Changing passwords every 90 days often causes people to create predictable passwords like:

```
Summer2024

Autumn2024

Winter2024
```

This actually makes passwords easier to guess.

---

# The Three Password Habits That Matter

## 1. Use a Different Password for Every Account

This is the single biggest protection against credential stuffing.

If one website is hacked:

```
Only that account is affected.
```

If passwords are reused:

```
One breach

↓

Every important account becomes vulnerable.
```

---

## 2. Use a Password Manager

Nobody can realistically remember hundreds of unique passwords.

Password managers solve this problem.

Examples:

- Bitwarden
- 1Password
- Dashlane
- Keeper

The lesson recommended **Bitwarden** because:

- Free
- Open Source
- Works across devices
- Automatically generates strong passwords

---

## 3. Enable Two-Factor Authentication (2FA)

Even if an attacker steals my password...

They still need my second authentication factor.

Examples:

- Authenticator App
- Mobile OTP
- Hardware Security Key

Important accounts that should always have 2FA enabled:

- Email
- Banking
- Password Manager
- Social Media
- Work Accounts

---

# Password Managers

A password manager stores all passwords securely.

Instead of remembering hundreds of passwords,

I only need to remember:

```
One strong master password.
```

Benefits:

- Generates random passwords
- Stores passwords securely
- Prevents password reuse
- Auto-fills login pages

# Password Security Summary

Good password security means:

✅ Long passwords

✅ Different password for every website

✅ Password Manager

✅ Enable 2FA

❌ Never reuse passwords

❌ Never rely only on complexity

---

# Password Attack Overview

| Attack | How It Works | Best Defense |
|---------|--------------|--------------|
| Credential Stuffing | Reused passwords from old breaches | Unique password for every account |
| Phishing | Fake login page steals password | Verify URLs + Enable 2FA |
| Dictionary Attack | Uses common password lists | Long unique passwords |
| Password Spraying | One password against many users | Strong uncommon passwords + MFA |
