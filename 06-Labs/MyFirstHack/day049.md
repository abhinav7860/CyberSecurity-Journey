## What I learned

Today I learned how to move around the Linux filesystem. Yesterday I learned how the filesystem is organised, and today I started using the main commands for navigating through it.

The three commands I need to remember the most are:

```text
pwd → where am I?
ls  → what's here?
cd  → how do I get there?
```

The basic rhythm is:

```text
cd → move
ls → look
pwd → confirm
```

## 1. `pwd`

`pwd` means **Print Working Directory**.

It shows the full path of where I currently am.

```bash
pwd
```

Example:

```text
/home/abhinav
```

This is useful whenever I get confused about my current location.

## 2. `ls`

`ls` means **list**. It shows the files and directories in the current location.

```bash
ls
```

I can also give it a specific path:

```bash
ls /etc
```

### Useful options

```bash
ls -l
```

Shows details like permissions, owner, size and modification date.

```bash
ls -a
```

Shows hidden files too.

```bash
ls -la
```

Shows detailed information including hidden files.

The `-a` option is useful to remember for security because hidden files can sometimes contain configuration or other important files.

## 3. `cd`

`cd` means **Change Directory**.

It is used to move around the filesystem.

```bash
cd Documents
```

Using an absolute path:

```bash
cd /var/log
```

Move up one directory:

```bash
cd ..
```

Move up two directories:

```bash
cd ../..
```

### Useful shortcuts

```bash
cd ~
```

or simply:

```bash
cd
```

takes me back to my home directory.

```bash
cd -
```

takes me back to the directory I was previously in.

## 4. Absolute vs Relative Paths

### Absolute path

Starts from `/`.

```text
/var/log
/home/abhinav/Documents
```

It works no matter where I currently am.

### Relative path

Starts from my current location.

```text
Documents
../Downloads
```

It depends on where I am.

Important symbols:

```text
.   = current directory
..  = parent directory
~   = home directory
```

## 5. Tab Completion

One of the most useful things I learned today is **Tab completion**.

Instead of typing the whole directory name, I can type part of it and press `Tab`.

For example:

```bash
cd Doc
```

then press `Tab`.

If there is a `Documents` directory, Linux can complete the name.

This saves typing and also helps avoid spelling mistakes.

If there are multiple matches, pressing `Tab` twice shows the available options.

## 6. Other Small Tricks

To clear the terminal:

```bash
clear
```

or:

```text
Ctrl + L
```

The **Up Arrow** brings back previous commands, so I don't have to type the same command again.

## What I took from this

Linux navigation is actually pretty simple. Most of the time I'm doing:

```text
pwd → check where I am
ls  → see what's there
cd  → move somewhere
```

The shortcuts like `..`, `~`, `cd -`, and Tab completion make it much easier.

Getting an error such as:

```text
No such file or directory
```

is normal if I type a wrong path. It doesn't mean I broke anything. I just need to check the path and try again.
