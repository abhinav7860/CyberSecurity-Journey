# Objective

Today I learned what actually happens when I type a website like **google.com** into my browser and press **Enter**.

Although it looks simple, several technologies work together in less than a second to load a webpage. Understanding these steps helped me see how networking and cybersecurity are connected.

---

# Computers Understand Numbers, Not Names

Humans use names like:

```
google.com
facebook.com
reddit.com
```

Computers only understand **IP addresses**.

Examples:

```
Google     → 142.250.191.46
Facebook   → 157.240.241.35
Reddit     → 151.101.1.140
```

Whenever we type a website name, it must first be translated into an IP address before communication can begin.

**Key Point:**

- Humans remember names.
- Computers communicate using IP addresses.

---

# DNS (Domain Name System)

DNS is like the **phonebook of the internet**.

Its job is to translate:

```
google.com
```

into

```
142.250.191.46
```

Without DNS, we would need to remember IP addresses for every website we visit.

---

# How DNS Works

When I enter:

```
google.com
```

the following happens:

1. Browser asks the Operating System.
2. Operating System asks the Router.
3. Router asks the ISP's DNS server.
4. DNS server finds Google's IP address.
5. The IP address is sent back to the browser.

Only after this translation can my browser contact Google's server.

---

# DNS Spoofing

I also learned about **DNS Spoofing**.

Instead of returning the real IP address, an attacker could send the IP address of a fake website.

Example:

I type:

```
bankofamerica.com
```

Instead of reaching the real website, the attacker redirects me to a fake login page.

If I enter my username and password, they get stolen.

This is one of the techniques used in phishing attacks.

---

# The Seven Steps of Loading a Website

Every time I open a website, these seven steps happen.

## 1. Browser Parses the URL

The browser reads:

```
https://google.com
```

and determines:

- Website
- HTTPS
- Port 443

---

## 2. DNS Lookup

The browser asks DNS for Google's IP address.

Example:

```
google.com

↓

142.250.xxx.xxx
```

---

## 3. TCP Handshake

The computer establishes a reliable connection with the server using TCP.

This is known as the **TCP Three-Way Handshake**.

---

## 4. TLS Handshake

The browser and server create an encrypted connection.

This is what gives websites the padlock icon.

HTTPS works because of TLS.

---

## 5. HTTP Request

The browser sends a request such as:

```http
GET /
```

which means:

"Send me the homepage."

---

## 6. Server Responds

The web server processes the request and sends back:

- HTML
- CSS
- JavaScript
- Images
- Other resources

---

## 7. Browser Renders the Page

Finally, the browser converts all the received data into the webpage that I see on my screen.

---

# Why These Seven Steps Matter

Every website I visit follows these same steps.

Understanding them also helps explain where cybersecurity tools operate.

Examples:

- Firewalls protect network connections.
- TLS encrypts communication.
- Web Application Firewalls inspect web requests.
- Antivirus scans downloaded files.
- EDR monitors processes running on the computer.

Knowing these steps makes it easier to understand how different security technologies work.

---

# Where Attackers Can Attack

Each step can become an attack point.

### Step 2 – DNS

Possible attack:

- DNS Spoofing
- DNS Poisoning

Result:

Users get redirected to fake websites.

---

### Step 3 – TCP

Possible attack:

- Man-in-the-Middle (MITM)

The attacker intercepts the connection between the user and the server.

---

### Step 4 – TLS

Possible attack:

- TLS Downgrade Attack

The attacker attempts to weaken or remove encryption.

---

### Step 5 – HTTP

Possible attacks:

- SQL Injection
- Cross-Site Scripting (XSS)

These attacks target web applications.

---

### Step 6 – Server

If the server itself is compromised, every visitor is affected, even if their connection is secure.

---

### Step 7 – Browser

Attackers may exploit browser vulnerabilities to execute malicious code simply by visiting a webpage.
