# The Router

A home router does much more than just provide Wi-Fi.

It is responsible for:

- Connecting my home network to the Internet.
- Assigning IP addresses (DHCP).
- Resolving DNS requests.
- Acting as a firewall.
- Broadcasting the Wi-Fi network.

One important thing I learned is that the **Wi-Fi password** and the **router admin password** are different.

- **Wi-Fi Password** → Used to connect devices to the network.
- **Admin Password** → Used to access and change router settings.

If someone gets the admin password, they can completely control the router.

# Wi-Fi Encryption Standards

Wi-Fi encryption protects wireless communication between devices and the router.

### WEP (1997)

- Very old.
- Can be cracked easily.
- Never use.

### WPA (2003)

- Improved over WEP.
- Also considered insecure today.

### WPA2 (2004)

- Most common standard.
- Secure when using **AES** encryption.

### WPA3 (2018)

- Latest and most secure standard.
- Recommended if all devices support it.

### Quick Revision

| Standard | Status |
|----------|--------|
| WEP | Broken |
| WPA | Broken |
| WPA2-AES | Good |
| WPA3 | Best |

# KRACK Attack

KRACK (Key Reinstallation Attack) was discovered in **2017**.

Instead of attacking the Wi-Fi password, it attacked the **WPA2 handshake** itself.

Important points:

- Affected WPA2 networks.
- Required firmware updates.
- Many old IoT devices are still unpatched.

# Public Wi-Fi Risks

Modern HTTPS protects most website data, but public Wi-Fi is still risky.

Possible attacks include:

- Evil Twin Wi-Fi
- DNS Manipulation
- Malicious Captive Portals
- Metadata collection (sites visited, timing, etc.)

Best practices:

- Prefer HTTPS websites.
- Use a VPN for sensitive work.
- Don't auto-connect to unknown Wi-Fi networks.

# Basic Home Router Security Audit

Things to check on a home router:

- Admin password changed from default.
- Wi-Fi encryption mode.
- Strong Wi-Fi password.
- Router firmware updated.
- Guest network available.
- Remote management disabled.
- Connected devices list reviewed.

These are the same basic checks a security analyst performs during a network assessment.

---

# Guest Network

A guest network separates visitors or IoT devices from my main devices.

Example:

Instead of putting everything on one network,

```
Main Network
├── Laptop
├── Phone
└── Smart TV

Guest Network
├── Smart Bulb
├── Camera
└── Guests
```

If an IoT device gets compromised, it cannot easily reach my laptop.

This security concept is called **Network Segmentation**.

---

# Password Strength

A strong Wi-Fi password is important because it protects access to the entire home network.

Good options include:

- 16+ random characters
- Long passphrases made of random words

Avoid:

- Dictionary words
- Birthdays
- Simple patterns
