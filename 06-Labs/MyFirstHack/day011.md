# The Web vs The Internet

One of the first things I learned was that the **Web is not the Internet**.

## Internet

The Internet is the global network that allows computers to communicate with each other.

It handles:

- Data transmission
- Routing packets
- DNS
- TCP/IP
- Network communication

---

## World Wide Web

The Web is a service that runs on top of the Internet.

It consists of:

- Websites
- Browsers
- Web servers
- Web pages

Simply put:

> **The Internet moves data, while the Web presents that data as webpages.**

---

# The Browser

I learned that browsers like:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

do much more than simply display webpages.

A browser acts as:

- Renderer
- Script Engine
- Network Client
- Storage System
- Security Boundary

---

## Renderer

The browser converts HTML and CSS into the webpage I see.

Without the renderer, websites would just be plain text.

---

## Script Engine

Browsers execute JavaScript.

JavaScript makes websites interactive by enabling:

- Buttons
- Forms
- Animations
- Live updates
- Notifications

---

## Network Client

The browser continuously sends and receives requests.

Examples include:

- HTML
- Images
- CSS
- JavaScript
- Fonts
- Videos

A single webpage may generate over **100 requests**.

---

## Storage System

Browsers also store information locally.

Examples include:

- Cookies
- Cache
- Local Storage
- Session Storage

These improve performance but can also become security risks if misused.

---

## Security Boundary

The browser decides:

- Which websites can communicate
- Which scripts can run
- Which cookies can be accessed
- Which data can be shared

This is one of the most important security responsibilities of a browser.

# What Happens When I Open a Website?

The lesson explained the complete process.

## Step 1 — DNS Lookup

The browser first asks:

```
What is the IP address of this domain?
```

Example:

```
bbc.co.uk
```

↓

```
151.101.x.x
```

---

## Step 2 — TCP Connection

The browser creates a TCP connection with the web server.

This is similar to establishing a phone call before speaking.

---

## Step 3 — TLS Handshake

If the website uses HTTPS:

```
https://
```

the browser performs a TLS handshake.

This establishes:

- Encryption
- Identity verification
- Secure communication

---

## Step 4 — HTTP Request

The browser sends an HTTP request such as:

```
GET /
```

asking for the webpage.

---

## Step 5 — HTTP Response

The server replies with:

- HTML
- CSS
- JavaScript
- Images
- Headers

---

## Step 6 — Resource Fetching

The browser discovers additional files inside the HTML.

Examples:

- CSS files
- Images
- Fonts
- JavaScript
- Videos

It automatically downloads them.

---

## Step 7 — Rendering

The browser builds the webpage.

It:

- Reads HTML
- Applies CSS
- Executes JavaScript

Finally displaying the webpage.

---

## Step 8 — Continuous Communication

Even after the page loads, communication continues.

Examples:

- Advertisements
- Analytics
- Notifications
- Live chats
- Auto refresh

---

# Security Risks During Page Loading

Each stage can be attacked.

Examples:

| Step | Possible Attack |
|-------|-----------------|
| DNS | DNS Poisoning |
| TCP | Session Hijacking |
| TLS | Downgrade Attack |
| HTTP | Response Manipulation |
| Resources | Malicious Scripts |
| JavaScript | XSS |

This made me realize that opening a webpage involves much more than simply loading a page.

# Front-End vs Back-End

The lesson clearly separated these two concepts.

---

## Front-End

Everything users see.

Includes:

- HTML
- CSS
- JavaScript

Runs inside the browser.

---

## Back-End

Everything running on the server.

Includes:

- Databases
- APIs
- Authentication
- Business Logic
- File Storage

Users never directly see the back-end.

---

# Why This Matters in Cybersecurity

Front-end attacks include:

- Cross Site Scripting (XSS)
- Fake Login Pages
- Malicious JavaScript

Back-end attacks include:

- SQL Injection
- Authentication Bypass
- Database Leaks
- Remote Code Execution

Most major data breaches happen because attackers eventually reach the back-end.

# Three Building Blocks of Every Website

Every webpage is built using three technologies.

---

## HTML

HTML defines the structure.

Examples:

- Headings
- Paragraphs
- Forms
- Images
- Links

Without HTML there is no webpage.

---

## CSS

CSS controls appearance.

Examples:

- Colors
- Fonts
- Layout
- Spacing
- Animations

---

## JavaScript

JavaScript controls behavior.

Examples:

- Login buttons
- Search boxes
- Dropdown menus
- Dynamic content
- API requests

JavaScript is also one of the most common attack surfaces in modern web applications.

The Elements tab displays the live HTML.

I can:

- View page structure
- Edit HTML

# Network Tab

The Network tab records every request made by the browser.

It shows:

- Images
- CSS
- JavaScript
- APIs
- Fonts
- Videos

Reloading the page displays every network request made during loading.

This is one of the most useful tabs for web application analysis.
