## What I Learned

Today I learned what a **SOC Analyst** actually does in a real cybersecurity environment.

SOC stands for **Security Operations Centre**. A SOC monitors an organisation's security, investigates suspicious activity, and responds to real threats.

The main levels are:

- **Tier 1:** Initial alert triage
- **Tier 2:** Deeper investigation
- **Tier 3:** Senior response and threat hunting

Most people enter through Tier 1.

---

## A Typical SOC Analyst Shift

A SOC analyst normally starts by opening the **SIEM** and checking alerts and the handover from the previous shift.

Most alerts are not actual attacks. The analyst has to investigate and decide whether they are false positives, suspicious activity, or real incidents.

### Impossible Travel Example

An alert might show a user logging in from two distant countries within a short time.

The analyst checks the authentication logs and discovers that the user was travelling and using a VPN. The VPN server was in another country, which caused the alert.

So it was a **false positive**.

The analyst documents the finding and closes the alert.

### DNS Tunneling Example

Another alert might show a workstation making a large number of DNS requests with long, random-looking subdomains to one unfamiliar domain.

This could indicate **DNS tunneling**, which I studied on Day 43.

The analyst collects DNS logs, packet captures, and timeline information before escalating the case to **Tier 2**.

This showed me that one of the main Tier 1 skills is knowing which alerts actually need further investigation.

## What the Job Is Really Like

SOC work is not just constantly fighting hackers.

A lot of the work involves:

- Checking alerts
- Investigating suspicious activity
- Reading logs
- Looking at network traffic
- Identifying false positives
- Documenting findings
- Escalating serious incidents
- Tuning detection rules
- Reviewing threat intelligence
- Writing handover notes

Most alerts can be harmless, so being able to separate normal activity from real threats is very important.

## Challenges of SOC Work

SOC monitoring can run 24/7, so analysts may have to work shifts, including nights or weekends.

Another challenge is **alert fatigue**. Analysts may deal with a large number of alerts, most of which are harmless.

Missing one real attack among thousands of alerts can have serious consequences.

But SOC work can also be a good starting point for a cybersecurity career.

From Tier 1, a person can move towards:

- Tier 2 / Tier 3
- Incident Response
- Digital Forensics
- Threat Hunting
- Penetration Testing
- Security Engineering
- Security Management
