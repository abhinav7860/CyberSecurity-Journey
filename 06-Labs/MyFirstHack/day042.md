## The Network You Trust Without Thinking

Most of the connections I use every day are wireless. Phones, laptops, watches and home devices connect through Wi-Fi and cellular networks.

Wireless is different from wired networking because the signal is broadcast through the air. Anyone within range may potentially receive it.

The main lesson is:

> **Don't trust a wireless network just because it looks familiar or has a strong signal.**

---

## The Evil Twin

An **evil twin** is a fake wireless access point that impersonates a legitimate network.

For example:

```text
Airport_Free_WiFi
```

An attacker could create another network with the same or a similar name.

From the victim's perspective, everything may appear normal:

- Wi-Fi connects
- Websites load
- Internet access works

The attacker can potentially place themselves in a man-in-the-middle position and see network metadata or interfere with unencrypted traffic.

A fake captive portal can also imitate a legitimate Wi-Fi login page and trick users into entering credentials.

### HTTPS Helps

HTTPS still protects the contents of properly encrypted connections.

Certificate warnings are important and should never be ignored.

A VPN can provide another encrypted tunnel between the device and the VPN server.

### Takeaway

Defences against evil twins include:

- HTTPS
- Paying attention to certificate warnings
- VPNs
- Being suspicious of unfamiliar Wi-Fi networks
- Avoiding reused credentials on captive portals

## Other Wireless Attacks

### Rogue Access Points

A rogue access point is an unauthorised wireless access point connected to a network.

It could be installed by an attacker or by an employee who doesn't understand the security risk.

It can create an unmonitored entry point into the network.

Defences include scanning for unauthorised access points and having policies against unauthorised wireless equipment.

### Deauthentication Attacks

Older Wi-Fi security did not properly authenticate some management messages.

An attacker could forge disconnect messages and force devices off a network.

Possible goals include:

- Denial of service
- Forcing devices to reconnect
- Creating an opportunity for other wireless attacks

Modern Wi-Fi security such as WPA3 provides better protection for management messages.

### Wi-Fi Password Attacks

When a device connects to a protected Wi-Fi network, a cryptographic exchange proves knowledge of the password without directly sending the password.

With older WPA2 networks, an attacker in range may capture this exchange and attempt to crack the password offline.

A weak password can be vulnerable to guessing, while a long and random password is much harder to crack.

WPA3 improves resistance against this type of offline password cracking.

> **Wi-Fi password strength matters.**

## Evolution of Wi-Fi Security

```text
WEP
 ↓
WPA
 ↓
WPA2
 ↓
WPA3
```

- **WEP:** Broken and should not be used.
- **WPA:** Improved security compared with WEP.
- **WPA2:** Still widely used but has known weaknesses.
- **WPA3:** Modern standard with improved protection.

### Practical Rule

> **Use the most modern Wi-Fi security your equipment supports, ideally WPA3.**

Never use WEP or an open network for sensitive activity.

## Defending Yourself on Networks You Don't Control

For cafes, airports, hotels and other public Wi-Fi:

> **Assume the network could be hostile.**

Use:

- HTTPS
- Certificate validation
- A VPN
- Caution with captive portals
- Suspicion toward network names

A strong Wi-Fi signal does not prove that a network is legitimate.

When possible, using cellular data or a personal hotspot can avoid many risks associated with unknown public Wi-Fi.

---

## Defending Networks You Control

For home or small-business Wi-Fi:

- Use WPA3 if supported.
- Use WPA2 at minimum.
- Never use WEP.
- Use a strong, long Wi-Fi password.
- Change default router administrator credentials.
- Keep router firmware updated.
- Use network segmentation.
- Separate guest devices from important systems.
- Consider a separate network for IoT devices.

## Wireless Security for Maya's Shop

Maya's customer Wi-Fi and business systems should be separated.

```text
                Router
                  |
        ┌─────────┴─────────┐
        ↓                   ↓
 Customer Wi-Fi        Business Network
                            |
                         POS / Till
                            |
                        Back Office
```

Customers should not share the same network as important business systems.

Her Wi-Fi should use WPA3 or at least WPA2 with a strong password.

Proper segmentation helps ensure that an attack against wireless users cannot directly reach important business systems.

## Wireless Security and Zero Trust

This connects directly to **Day 40 — Zero Trust**.

> **Never trust, always verify.**

Don't trust a Wi-Fi network because:

- The name looks correct.
- The signal is strong.
- It automatically connects.
- Other people are using it.

Trust should come from:

- Encryption
- Validated certificates
- Known-good configuration
- Proper network security

## Cellular Networks

Cellular networks such as 4G and 5G are generally more secure against casual attacks than open public Wi-Fi.

However, cellular networks are not perfectly secure.

### IMSI Catchers

Devices sometimes called **IMSI catchers** or **Stingrays** can impersonate cellular towers.

This is similar to the impersonation idea behind an evil twin.

The important lesson is:

> **No wireless medium is completely immune to impersonation.**

Strong end-to-end encryption such as HTTPS and encrypted messaging still provides important protection.

## Wireless Security Is an Arms Race

Wireless security continues to evolve:

```text
WEP
 ↓
Broken
 ↓
WPA
 ↓
WPA2
 ↓
WPA3
```

The more useful skill is understanding the underlying problems.

### Vulnerabilities

- Broadcast communication
- Trusting network names
- Weak Wi-Fi passwords
- Unauthenticated management messages
- Unauthorised access points

### Defences

- Strong encryption
- Verification instead of trust
- Modern Wi-Fi standards
- Strong passwords
- Network segmentation
- Updated equipment

Security is never finished.

## Legal and Ethical Line

Wireless testing should only be performed on:

- Equipment I own
- A lab environment I am authorised to use
- Networks where I have explicit written permission to test

I should not capture traffic, crack Wi-Fi passwords, create evil twins, or perform deauthentication attacks against networks I don't own or have permission to test.

> **Knowledge is for protection. Authorisation matters.**

## Important Terms

### Evil Twin
A fake wireless access point that impersonates a legitimate network.

### Rogue Access Point
An unauthorised wireless access point connected to a network.

### Deauthentication Attack
An attack that abuses Wi-Fi management messages to force devices to disconnect.

### WPA2
A widely used Wi-Fi security standard with known weaknesses including offline password cracking against captured authentication exchanges.

### WPA3
A newer Wi-Fi security standard that improves protection against several older attacks.

### WEP
An outdated and broken Wi-Fi security protocol that should not be used.

### Captive Portal
A web page shown when connecting to some public Wi-Fi networks.

### IMSI Catcher
A device that can impersonate a cellular network tower.

### VPN
A technology that creates an encrypted tunnel between a device and a VPN server.

## Key Takeaways

- Wireless signals are broadcast through the air.
- An evil twin impersonates a legitimate Wi-Fi network.
- Rogue access points create unauthorised entry points.
- Older Wi-Fi networks can be vulnerable to deauthentication attacks.
- WPA2 authentication exchanges can potentially be captured and attacked offline.
- Strong Wi-Fi passwords are important.
- WEP is broken and should never be used.
- WPA3 is preferred when supported.
- HTTPS protects properly encrypted connections.
- Certificate warnings should never be ignored.
- VPNs add another layer of protection on untrusted networks.
- Cellular networks are generally safer than unknown open Wi-Fi for casual use.
- IMSI catchers show that cellular networks can also be impersonated.
- Network segmentation limits the impact of wireless compromise.
- Wireless networks should not be trusted simply because the network name looks familiar.
- Wireless security testing should only be performed with proper authorisation.
