# 📖 1. Why Mobile Security is Different

Modern smartphones are not simply small computers. They have a unique
security architecture designed around apps, permissions, and messaging.

## Key Differences

### 🔒 Sandboxed Applications

-   Every app runs inside its own isolated environment.
-   Apps cannot access each other's data without permission.

### ✅ Permission-Based Access

Applications request access to: - Camera - Microphone - Contacts -
Storage - Location

Always question unnecessary permissions.

### 🔄 Update Lifecycle

-   Android updates depend on manufacturers.
-   Older devices eventually stop receiving security patches.

### 💬 Message-Based Attack Surface

Most attacks arrive through: - SMS - WhatsApp - Telegram - iMessage

### 🔐 Biometric Authentication

Phones rely on: - Fingerprint - Face ID - PIN

An unlocked phone gives attackers immediate access.

# 🚨 2. Pegasus Spyware

Pegasus is advanced spyware capable of compromising phones.

## Important Facts

-   Initially required victims to click a malicious link.
-   Later evolved into **Zero-Click Exploits**.
-   Could access:
    -   Messages
    -   Photos
    -   Camera
    -   Microphone
    -   LocatioN

### Key Lesson

State-sponsored attacks often become criminal attacks later.

------------------------------------------------------------------------

# ⚠️ 3. Common Mobile Threats

## Smishing (SMS Phishing)

Fake SMS messages pretending to be: - Banks - Delivery companies -
Government agencies

Goal: - Steal credentials - Install malware

## Malicious Applications

Fake apps disguised as: - QR scanners - File managers - Photo editors

## Sideloading

Installing APKs outside official app stores increases risk.

## Public Wi-Fi

Risks include: - Rogue hotspots - Traffic interception - Credential
theft

## Lost or Stolen Devices

Weak PINs and unlocked phones expose sensitive information.

------------------------------------------------------------------------

# 🔍 4. Mobile Security Checklist

Review the following:

-   Latest Operating System
-   App Permissions
-   Strong Lock Screen
-   Avoid SMS-based 2FA when possible
-   Remove unused applications
-   Enable Find My Device / Find My iPhone
-   Enable Lockdown Mode (if required)

------------------------------------------------------------------------

# 📲 5. Why SMS 2FA is Weak

## SIM Swapping

Attackers convince a carrier to transfer your phone number to their SIM
card.

Result: - SMS verification codes go to the attacker.

Better options: - Authenticator Apps - Hardware Security Keys

------------------------------------------------------------------------

# 🧪 6. Practical Exercise -- Spot Smishing

Check recent SMS messages for:

-   Fake parcel delivery
-   Fake bank alerts
-   Prize scams
-   Account suspension notices

Before clicking: 1. Verify sender number. 2. Inspect the URL. 3. Check
if the story makes sense. 4. Report spam if necessary.
