# 1. CIA Triad

The CIA Triad is the foundation of cybersecurity. Every security measure is designed to protect one or more of these three principles.

### Confidentiality

Confidentiality means protecting information from unauthorized access.

**Example:** Passwords, encryption, OTPs.

---

### Integrity

Integrity means making sure data is not modified without permission.

**Example:** Checksums, hashing, digital signatures.

---

### Availability

Availability means making sure systems and services are always accessible when needed.

**Example:** Backup servers, redundancy, UPS.

---

# 2. Vulnerability

A vulnerability is any weakness that an attacker can exploit.

Examples:

- Weak passwords
- Outdated software
- Open ports
- Unpatched systems

---

# 3. Ethical Hacking Rules

Before performing any security testing:

- Always get proper authorization.
- Never destroy or modify data.
- Document everything you do.

---

# 4. TCP/IP Model

The TCP/IP model has **4 layers**.

1. Application Layer
2. Transport Layer
3. Internet Layer
4. Network Access Layer

It is the model used in real-world networking and on the Internet.

---

# 5. OSI Model

The OSI Model has **7 layers**.

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

It is mainly used to understand how data travels through a network and for troubleshooting.

---

# 6. TCP vs UDP

### TCP

- Connection-oriented
- Reliable
- Slower
- Checks if data is delivered correctly

Examples:
- HTTP/HTTPS
- FTP
- Email

### UDP

- Connectionless
- Faster
- Less reliable
- No guarantee that data reaches the destination

Examples:
- Video Streaming
- Online Gaming
- VoIP

---

# 7. Cyber Attacks on OSI Layers

Different attacks can happen at different OSI layers.

Examples:

- Physical Layer → Cable cutting, hardware damage
- Data Link Layer → MAC flooding
- Network Layer → IP spoofing
- Transport Layer → SYN Flood
- Application Layer → SQL Injection, XSS
