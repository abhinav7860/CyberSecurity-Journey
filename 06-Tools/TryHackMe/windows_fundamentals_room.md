# What I Learned

## Windows Desktop (GUI)

The Windows Desktop is the graphical interface users interact with after logging into Windows. It provides quick access to applications, files, folders, and system settings.

Main components include:

- Desktop
- Start Menu
- Search Box
- Task View
- Taskbar
- Notification Area

---

## Desktop

The desktop stores shortcuts to applications, folders, and files for quick access.

I learned that users can:

- Change wallpaper
- Change themes
- Adjust display resolution
- Organize icons
- Create new folders and shortcuts

---

## Start Menu

The Start Menu acts as the central location for accessing installed applications and Windows settings.

It contains:

- User account options
- Recently installed applications
- Installed programs
- Power options
- Settings
- Documents and Pictures shortcuts

I also learned that applications can be pinned to the Start Menu for faster access.

---

## Taskbar

The Taskbar displays currently running applications and allows quick switching between them.

Features include:

- Open application icons
- Search
- Task View
- Pinned applications
- Preview thumbnails

---

## Notification Area

Located at the bottom-right corner of the screen, the Notification Area displays:

- Date & Time
- Network status
- Volume controls
- System notifications
- Background applications

---

## Windows File System

I learned that Windows organizes data using drives such as:

- C:\
- D:\
- External drives

Important folders include:

- Desktop
- Documents
- Downloads
- Pictures
- Program Files
- Windows

---

## Windows\System32

The **System32** folder contains essential operating system files required for Windows to function properly.

I learned that:

- It stores important system files.
- It should not be modified unless necessary.
- Many Windows utilities are stored here.

---

## User Accounts & Permissions

Windows allows multiple users on a single computer.

Different account types include:

- Administrator
- Standard User

Permissions determine what users are allowed to access or modify.

---

## User Account Control (UAC)

User Account Control (UAC) is a Windows security feature that helps prevent unauthorized changes to the operating system.

When administrator privileges are required, Windows prompts the user for confirmation before allowing the action.

This adds an extra layer of protection against malware and accidental system changes.

---

## Settings & Control Panel

Both Settings and Control Panel are used to configure Windows.

Examples include:

- Network settings
- Personalization
- Display settings
- User accounts
- Installed applications
- Windows Update

---

## Task Manager

Task Manager allows users to monitor and manage running processes.

Functions include:

- View running applications
- End unresponsive programs
- Monitor CPU and Memory usage
- View startup applications
- Monitor system performance

Task Manager is one of the first tools used when troubleshooting Windows systems.
