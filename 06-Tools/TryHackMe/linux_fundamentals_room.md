# Commands I Learned

| Command  | Purpose                               |
| -------- | ------------------------------------- |
| `echo`   | Display text in the terminal          |
| `whoami` | Show the current logged-in user       |
| `pwd`    | Display the current working directory |
| `ls`     | List files and directories            |
| `cd`     | Change directories                    |
| `cat`    | Display file contents                 |
| `find`   | Search for files and folders          |
| `grep`   | Search for specific text inside files |

---

# Shell Operators

| Operator | Purpose                                                        |
| -------- | -------------------------------------------------------------- |
| `&`      | Run commands in the background                                 |
| `&&`     | Execute the next command only if the previous command succeeds |
| `>`      | Redirect output to a file (overwrites existing content)        |
| `>>`     | Append output to the end of a file                             |
