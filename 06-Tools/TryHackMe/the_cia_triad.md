# The CIA Triad

The CIA Triad is one of the most important security models in cybersecurity.

It consists of three core principles:

- **Confidentiality**
- **Integrity**
- **Availability**

Every security control or cyber attack can generally be explained by how it affects one or more of these three principles.

---

# Confidentiality

## Definition

Confidentiality ensures that sensitive information is only accessible to authorized users.

If unauthorized individuals gain access to information, confidentiality has been compromised.


### Common Security Controls

- Encryption
- Strong Passwords
- Multi-Factor Authentication (MFA)
- Access Control
- User Permissions

---

# Integrity

## Definition

Integrity ensures that information remains accurate, complete, and unaltered unless modified by an authorized user.

Unauthorized changes to data compromise its integrity.


### Common Security Controls

- Hashing
- Digital Signatures
- Audit Logs
- Access Controls

---

# Availability

## Definition

Availability ensures that systems, applications, and data remain accessible whenever authorized users need them.

A secure system is of little use if legitimate users cannot access it.


### Common Security Controls

- Backups
- Redundant Systems
- Load Balancing
- Disaster Recovery
- UPS / Backup Power

# Hands-on Exercise

As part of this room, I completed an interactive exercise where I classified different security incidents according to the affected CIA principle.

### Confidentiality

- Sensitive customer data leaked through an unsecured backup.
- Employee salary files exposed publicly.
- Login credentials shared with an unauthorized person.

### Integrity

- Database record modified without authorization.
- Financial report altered.
- System logs deleted to hide malicious activity.

### Availability

- Critical updates blocked, preventing services from running.
- Company website unavailable during business hours.
- Email server taken offline due to a Denial-of-Service (DoS) attack.
