# Linux Basics - Day 01

## Overview

Today I learned the fundamental Linux commands used for navigating the file system, managing files and directories, viewing file contents, searching for files, changing permissions, and compressing files.

## Topics Covered

- Linux file system navigation
- File and directory management
- Viewing and searching files
- File permissions
- Compression and archiving
- Disk usage commands
