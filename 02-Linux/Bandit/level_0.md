## What I Learned

This level introduced me to **SSH**, which allows me to securely connect to a remote Linux machine.

After logging in, I learned how to check my current directory and list files before reading a file.

---

## Commands Explained

### ssh

Used to securely connect to another computer over the network.

Example:

```bash
ssh username@hostname
```

### ls

Lists all files and folders in the current directory.

### cat

Displays the contents of a text file.
