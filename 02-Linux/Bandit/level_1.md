# Bandit Level 1 → Level 2

## Objective

Find the password stored inside a file named `-`.

---

## Commands Used

```bash
cat ./-
```

---

## What I Learned

Normally, `-` is treated as an option by Linux commands.

Using `./` tells Linux that `-` is actually a filename in the current directory.

---

## New Concept

### Relative Path

```
./
```

means "look in the current directory."
