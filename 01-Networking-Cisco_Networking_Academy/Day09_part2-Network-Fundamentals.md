# Day 8 - TCP, UDP & Port Numbers

# 1. TCP vs UDP

The Transport Layer is responsible for delivering data from one application to another. It mainly uses two protocols:

- TCP (Transmission Control Protocol)
- UDP (User Datagram Protocol)

## TCP (Reliable Communication)

TCP makes sure that data reaches the destination correctly.

Features:
- Connection-oriented
- Reliable
- Uses acknowledgements (ACK)
- Retransmits lost packets
- Data arrives in the correct order

Think of TCP like sending an important courier package. The receiver signs after receiving it, and if the package is lost, another one is sent.

Examples:
- HTTP / HTTPS
- FTP
- SSH
- Email

---

## UDP (Fast Communication)

UDP focuses on speed instead of reliability.

Features:
- Connectionless
- No acknowledgements
- No retransmission
- Faster than TCP

Think of UDP like a live TV broadcast. If you miss a few seconds, the video keeps playing instead of stopping to recover the lost data.

Examples:
- DNS
- VoIP
- Video Streaming
- Online Gaming

---

# TCP vs UDP

| TCP | UDP |
|------|------|
| Reliable | Fast |
| Uses ACK | No ACK |
| Retransmits lost packets | Doesn't retransmit |
| Ordered delivery | No guarantee of order |
| Slower | Faster |

# 2. Port Numbers

A port number identifies which application should receive the data.

Even though one computer has a single IP address, multiple applications can communicate at the same time because each application uses a different port.

Example:

```
Web Browser  → Port 80
SSH          → Port 22
DNS          → Port 53
```

---

# 3. Common Port Numbers

```
20   FTP Data
21   FTP Control
22   SSH
23   Telnet
25   SMTP
53   DNS
67   DHCP Server
68   DHCP Client
69   TFTP
80   HTTP
110  POP3
143  IMAP
161  SNMP
443  HTTPS
```

These are called **Well-Known Ports** because they are reserved for common services.

---

# 4. Source Port vs Destination Port

Every communication contains two ports.

- Source Port → Randomly generated by the client.
- Destination Port → Fixed port of the service being requested.

Example:

```
My PC
IP: 192.168.1.5
Source Port: 1099

↓

Web Server
IP: 192.168.1.7
Destination Port: 80
```

The web server knows the request is for HTTP because the destination port is **80**.

---

# 5. Socket

A socket is simply:

```
IP Address + Port Number
```

Example:

```
192.168.1.5:1099
```

This identifies one application running on a device.

---

# 6. Socket Pair

Communication always happens between **two sockets**.

Example:

```
Client
192.168.1.5:1099

↓

Server
192.168.1.7:80
```

Socket Pair:

```
192.168.1.5:1099
↓

192.168.1.7:80
```

This uniquely identifies one conversation between a client and a server.

# 7. netstat Command

`netstat` is used to view active network connections.

It displays:
- Active connections
- Local IP
- Remote IP
- Port numbers
- Connection state

Syntax:

```bash
netstat
```

To display numeric IP addresses and port numbers:

```bash
netstat -n
```

---

## Practical Example

On Kali Linux:

```bash
netstat -tulnp
```

Shows:

- Listening TCP ports
- Listening UDP ports
- Running services
- Process IDs

This is useful during penetration testing to see which services are running on a machine.
