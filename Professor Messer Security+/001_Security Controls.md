# What are Security Controls?

Security controls are the safeguards used to protect systems, networks, people, and data from threats. They help prevent attacks, detect suspicious activity, recover from incidents, and enforce security policies.

Security controls are divided into:

- Categories (What kind of control it is)
- Control Types (What the control actually does)

---

# Categories of Security Controls

## 1. Technical Controls

Technical controls are implemented using hardware or software.

### Examples
- Firewall
- Antivirus
- IDS/IPS
- Multi-Factor Authentication (MFA)

**Purpose:** Protect systems using technology.

---

## 2. Managerial Controls

Managerial controls are created by management to define how security should be handled.

### Examples

- Security policies
- Procedures
- Risk assessments
- Compliance requirements

**Purpose:** Guide employees on how security should be managed.

---

## 3. Operational Controls

Operational controls are carried out by people during daily operations.

### Examples

- Security guards
- Security awareness training
- Incident response procedures
- Reception desk

**Purpose:** Protect the organization through people and daily processes.

---

## 4. Physical Controls

Physical controls protect buildings, equipment, and other physical assets.

### Examples

- Door locks
- Badge readers
- Fences
- CCTV cameras
- Security gates

**Purpose:** Prevent unauthorized physical access.

---

# Types of Security Controls

## 1. Preventive Control

Stops an attack before it happens.

### Examples

- Firewall
- Door lock
- Antivirus
- MFA

**Easy to remember:**
> Prevent something before it happens.

---

## 2. Deterrent Control

Discourages attackers from attempting an attack.

### Examples

- Warning signs
- Security cameras
- Splash screens
- Security guards

**Easy to remember:**
> Makes attackers think twice.

---

## 3. Detective Control

Identifies or discovers that something has happened.

### Examples

- System logs
- Motion detectors
- IDS
- Login reports

**Easy to remember:**
> Detects suspicious activity.

---

## 4. Corrective Control

Reduces the impact after an incident and helps recover.

### Examples

- Fire extinguisher
- Backup recovery
- Malware removal
- Disaster recovery

**Easy to remember:**
> Fixes the problem after it occurs.

---

## 5. Compensating Control

Used when the original security control cannot be implemented.

### Examples

- Blocking access until a patch is available
- Power generator
- Separation of duties

**Easy to remember:**
> An alternative security control.

---

## 6. Directive Control

Provides instructions or rules that people must follow.

### Examples

- Security policies
- Compliance policies
- "Authorized Personnel Only" signs
- Security awareness training

**Easy to remember:**
> Tells people what they should do.

---

# Quick Comparison

| Control Type | Purpose |
|--------------|---------|
| Preventive | Stop attacks before they happen |
| Deterrent | Discourage attackers |
| Detective | Detect suspicious activity |
| Corrective | Recover after an incident |
| Compensating | Alternative control when the main one isn't possible |
| Directive | Guide people through rules and policies |
