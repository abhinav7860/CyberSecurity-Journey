# What is the AAA Framework?

AAA is one of the most common security frameworks used in organizations.

It helps answer four important questions:

1. Who are you?
2. Can you prove it?
3. What are you allowed to access?
4. What did you do after logging in?

Every secure login system follows these steps.

---

# 1. Identification

Identification is simply claiming who you are.

Usually, this is done using:

- Username
- Email address
- Employee ID

### Example

```
Username: abhinav.sabu
```

At this stage, the system only knows who you claim to be.

It does **NOT** verify your identity yet.

### Easy to Remember

> Identification = "I am Abhinav."

---

# 2. Authentication

Authentication proves that you are actually the person you claim to be.

This can be done using:

- Password
- Fingerprint
- Face ID
- OTP
- Security Key
- Smart Card

### Example

After entering your username, you enter your password.

If the password is correct, you are authenticated.

### Easy to Remember

> Authentication = "Prove it."

---

# Authenticating People

When a user logs in, the request usually follows this process:

```
Client
   │
Internet
   │
Firewall / VPN
   │
AAA Server
   │
Credentials Verified
   │
Internal Resources
```

The AAA server verifies the user's credentials before granting access.

---

# Authenticating Systems (Devices)

Sometimes devices also need to prove their identity.

Examples:

- Company laptops
- Servers
- Routers
- IoT devices

A device cannot type a password like a person.

Instead, devices usually use **Digital Certificates**.

The certificate proves that the device is trusted.

### Why is this useful?

- Secure VPN connections
- Device management
- Trusted communication between systems

### Easy to Remember

> People use passwords.

> Devices use certificates.

---

# 3. Authorization

Authentication tells the system **who you are.**

Authorization decides **what you are allowed to do.**

Different users receive different permissions.

### Example

Employee

✔ View files

❌ Delete files

---

Administrator

✔ View files

✔ Create users

✔ Delete users

✔ Change system settings

### Easy to Remember

> Authentication comes first.

> Authorization comes after authentication.

---

# Authorization Models

Instead of assigning permissions to every individual user, organizations use authorization models.

This makes management much easier.

Common models include:

- Role-Based Access Control (RBAC)
- Attribute-Based Access Control (ABAC)
- Organization-based permissions

### Example

Instead of giving permissions to 500 employees individually,

Create a role called:

```
HR Manager
```

Everyone with that role automatically gets the required permissions.

---

# 4. Accounting

Accounting records everything a user does after logging in.

It creates an audit trail.

Information that may be recorded:

- Login time
- Logout time
- Files accessed
- Commands executed
- Data uploaded
- Data downloaded

### Why is it important?

If a security incident happens, administrators can check the logs to find out what occurred.

### Easy to Remember

> Accounting = Logging and Monitoring.

---

# Quick Comparison

| Step | Question Answered |
|-------|-------------------|
| Identification | Who are you? |
| Authentication | Can you prove it? |
| Authorization | What are you allowed to access? |
| Accounting | What did you do? |

# Real-Life Example

Imagine entering your college library.

### Identification

You say,

> "I'm Abhinav."

### Authentication

You show your student ID.

The librarian confirms it's really you.

### Authorization

Students can borrow books.

Staff members can access restricted rooms.

The permissions depend on the person's role.

### Accounting

The library records:

- Entry time
- Exit time
- Books borrowed
- Books returned

Everything is logged.

---

# Exam Tips 📝

✅ Authentication always happens **before** Authorization.

✅ Devices usually authenticate using **Digital Certificates**.

✅ Accounting is all about **logging, auditing, and monitoring**.

✅ AAA questions are very common in the Security+ exam.
