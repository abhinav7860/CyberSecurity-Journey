# CyberSecurity Journey

**A hands-on journey through cybersecurity, ethical hacking, security tools, and practical labs.**

**Start Date:** 28 June 2026

Welcome to my cybersecurity learning repository! 👋

I'm a Computer Science and Engineering graduate building my knowledge and practical skills across different areas of cybersecurity through structured learning, hands-on labs, CTF challenges, and personal projects.

This repository documents my progress throughout my cybersecurity training journey, including practical exercises, technical notes, tool usage, investigation workflows, and projects.

My goal is to develop a strong foundation across both defensive and offensive security while building practical skills relevant to entry-level cybersecurity roles.

## 🚀 Projects & Practical Work

- **Home Vulnerability Scanner:** Exploring host and service discovery, banner grabbing, and basic vulnerability checks.
- **SIEM-to-Firewall Automation:** Developing a workflow that connects SIEM alerts with indicator extraction, decision-making, and firewall blocking.

Projects may be in different stages of development. Their documentation should describe their current functionality, implementation, limitations, and testing results.
